## 技术要点

### 结巴分词标签云方案
- 使用 `jieba.posseg.pseg.lcut()` 进行分词和词性标注
- 只保留名词（`flag.startswith('n')`）和英文/数字（`eng`, `x`, `t`）
- 扩展停用词表 ~80 个词，过滤无意义高频词
- 频率阈值 `cnt >= 2`，最终取 TOP 15

### Windows 定时任务关键点
- 使用 `SYSTEM` 账户运行，不受用户登录状态影响
- `PYTHONUTF8=1` 环境变量解决 UTF-8 编码问题
- 日志记录到 `logs\scheduler.log`
- 任务计划程序中可设置多个触发器实现一天多次更新

## 运行命令
```powershell
$env:PYTHONUTF8=1; python.exe -X utf8 fetch_news.py
```
